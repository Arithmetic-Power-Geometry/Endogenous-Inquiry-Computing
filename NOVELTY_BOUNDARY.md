# Novelty Boundary

EIC does **not** claim novelty for problem finding, problem setting, automated problem formulation, belief revision, causal discovery, MDL/model selection, open-world learning, curiosity, reward uncertainty, world models, or scientific agents individually.

The proposed research object is the **task-defining frame transition as a first-class computational state transition**, including explicit structural cost and changes to admissible information, variables, relations, objectives, actions, validation rules, or hypothesis language.

The theory contains a deliberate collapse case: when all candidate frames and all their information/action interfaces are freely available in a static superframe, terminal frame selection can be represented as ordinary model selection. EIC is scientifically meaningful only where explicit frame structure yields operational, informational, semantic, path-cost, or theoretical distinctions.
